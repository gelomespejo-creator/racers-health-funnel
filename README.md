# The Racer's Health — Lead Funnel

Landing page and thank-you page for the free 2-chapter preview of *The Racer's Health*.

## Structure

- `index.html` — main landing page (hero, free-preview breakdown, credibility, full-book teaser, signup forms)
- `thank-you.html` — post-signup confirmation page with Meta Pixel Lead event
- `style.css` — all styling (dark motorsport theme, teal accent)
- `assets/` — book cover mockup

## Setup still needed

Search for these placeholder markers in `index.html` and `thank-you.html` and replace with real values:

- `KIT (CONVERTKIT) FORM — REPLACE THIS BLOCK` — paste your Kit form embed code
- `YOUR_PIXEL_ID` — your Meta Pixel ID
- `BUY NOW LINK` — your Kit Commerce checkout link once the full book is live for sale

Full setup instructions are in the funnel setup guide shared separately.
